# Submission Manifest

This package contains the final submission for the N-Queens SAT project.

## Components
- `paper/`: Contains the compiled PDF and all LaTeX source files.
- `figures/`: All generated figures (PDF/PNG) used in the paper.
- `tables/`: Processed CSVs containing summary and raw performance data.
- `source/`: Source code (see GitHub).
- `NQueens_SAT_Final_Submission.zip`: The complete packaged archive.
