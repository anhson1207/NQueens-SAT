# Figure Captions

**Figure 1 — SAT Runtime vs N (`fig01_sat_runtime_vs_n`)**
Comparison of the median pipeline total time (seconds) across five SAT encodings (Pairwise, Binary, Sequential, Commander, Product) as a function of the board size $N$. The timeout limit is set to 300 seconds. Data is based on 5 repetitions per configuration using the `solver_default` phase policy. Runs that exceed the timeout are excluded from the median calculation.

**Figure 2 — Exact Solver Runtime vs N (`fig02_exact_solver_runtime_vs_n`)**
Median pipeline total time (seconds) of four exact solvers (OR-Tools CP-SAT, Gurobi MIP, IBM CPLEX MIP, IBM CP Optimizer) across board sizes $N$. Data is based on 5 repetitions per solver. Note that license restrictions artificially cap the solvable instances for CPLEX MIP ($N \le 31$) and Gurobi MIP ($N \le 44$); lines are discontinuous beyond these points.

**Figure 3 — All Nine Methods at N=20 (`fig03_all_methods_n20`)**
A horizontal bar chart comparing the mean runtime performance (seconds) of all nine methods exclusively at $N=20$. Error bars or variability indicators denote the standard deviation across 5 repetitions. All solvers successfully solve the $N=20$ problem within the 300-second time limit.

**Figure 4 — SAT CNF Clause Growth (`fig04_sat_clause_growth`)**
The growth of the number of CNF clauses generated by each of the five SAT encodings relative to the board size $N$. This reflects the structural complexity and memory overhead of the encodings before the SAT solver's simplification phase.

**Figure 5 — SAT Auxiliary Variable Overhead (`fig05_sat_variable_overhead_n100`)**
A stacked bar chart comparing the variable overhead of the five SAT encodings specifically at $N=100$. The bars are partitioned into primary variables (representing the board layout) and auxiliary variables (introduced by the encoding structures).

**Figure 6 — Completion/Timeout Matrix (`fig06_completion_matrix`)**
A heatmap matrix illustrating the completion status of all nine methods across 11 board sizes. Categorical statuses differentiate between successful runs (SAT), timeouts (>300s), license restrictions, and other failures, aggregated over 5 repetitions.

**Figure 7 — Runtime Variability (`fig07_runtime_variability`)**
A dot plot (or boxplot) showing the runtime distribution and variance across the 5 repetitions for each method at various sizes of $N$. Timeouts and license-blocked runs are omitted from this distribution.
